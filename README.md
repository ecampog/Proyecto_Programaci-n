# ⚽ DataLab: Goles de la Copa Mundial (The Com)

Herramienta de análisis de datos desarrollada en Python para la  consulta y estadística de un dataset histórico de goles en los mundiales de fútbol.

## 📊 Dataset Elegido
* **Descripción:** Registro histórico de goles en diferentes ediciones de la Copa Mundial de la FIFA (incluyendo información de partidos, selecciones, jugadores, minutos y tipo de anotación).
* **Archivos incluidos:**
  * `goals.csv`: Dataset completo (200+ registros) para las siguientes fases.

## ❓ Preguntas de Investigación
1. ¿Qué selección nacional anota la mayor cantidad de goles?
2. ¿En qué minuto del partido se concentra la mayor cantidad de anotaciones?
3. ¿Cuál es el comportamiento de los goles de penalti vs. jugada en cancha?
